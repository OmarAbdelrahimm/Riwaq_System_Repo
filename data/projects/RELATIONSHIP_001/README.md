# RELATIONSHIP_001 — «العلاقات أعمق من التواصل»

مقطع Riwaq أفقي 16:9 بطول 4:30، مبني على الفيديو الذي أعدّه المستخدم من حلقة «مركزية العلاقة مع الله» لياسر الحزيمي. النسخة الجديدة تستخدم الصورة والصوت الأصليين، لا تعليق `voice-00` التجريبي.

## المعالجة

- مصدر الفيديو: 1920×1080، 25fps، مدة 270 ثانية. يُعرض عند 75% داخل إطار ذهبي Riwaq فوق خلفية فحمية ذات نسيج ورقي خفيف.
- الصوت: مسار AAC الأصلي، مستخرجًا دون إعادة ترميز إلى `public/projects/RELATIONSHIP_001/source/relationship_audio.m4a`، مع خلفية موسيقية دافئة عند −27 dB.
- العناوين: أربعة فصول قصيرة تتبع حديث المقطع عن الفرق بين التواصل والعلاقة، ثم استعارة اللوحة المشتركة، وعناصر العلاقة، وسياق الإنسان.
- الكابشنز: 41 cue عربيًا مبنية على المسار العربي المضمّن في المصدر ومهذّبة للعرض. يسمح إعداد هذا المشروع الأفقي بحد 44 حرفًا للسطر، مطابقًا لالتفاف النص في الفيديو. يلزم تدقيق بشري نهائي لعبارات التفريغ مقابل الصوت قبل النشر.
- العناصر البصرية: إطار ذهبي رفيع، نسيج Riwaq، وعلامات رمزية متحركة بهدوء تتبدل بين التواصل واللوحة والعناصر والسياق.

## المصدر والخصوصية

ملف المصدر محفوظ محليًا في `public/projects/RELATIONSHIP_001/source/relationship_source.mp4`، والصوت المنفصل في `relationship_audio.m4a`. مجلد `source/` مستثنى من Git لتجنب إعادة توزيع ملف Drive الأصلي؛ يلزم وضع المصدر في هذا المسار قبل إعادة الريندر على جهاز آخر. أكد المستخدم امتلاك الحقوق/الإذن لاستخدام اللقطات والصوت.

## التشغيل

```bash
npm run props:relationship
npm run srt:relationship
npm run render:relationship:final
```

يُنشأ الفيديو في `exports/RELATIONSHIP_001_RIWAQ_FINAL.mp4` (مخرجات `exports/` محلية وغير مضافة إلى Git). المعاينة نصف الدقة متاحة عبر `npm run render:relationship:preview`.

## المسودة السابقة

`exports/RELATIONSHIP_001_DRAFT_VO.mp4` هي مسودة مستقلة أُنتجت سابقًا بصوت توليدي مؤقت للتوقيت فقط؛ ليست النسخة المطلوبة الجديدة ولا تُستخدم ملفاتها الصوتية في هذا التكوين.
