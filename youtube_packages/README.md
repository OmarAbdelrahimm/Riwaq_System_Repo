## إعادة التوليد

راجع `../scripts/youtube_bundle/README.md` وثبّت `python -m pip install -r scripts/youtube_bundle/requirements.txt` في بيئة معزولة، ثم شغّل `python scripts/youtube_bundle/build.py`. لا يحتوي المستودع على أي ملف MP4؛ نُسخت الفيديوهات الأصلية من Drive على الخادم دون فكّها أو إعادة ترميزها.

## مراجعة الأغلفة — 2026-10-23

أُعيد بناء 48 غلافًا محليًا (12 حزمة × 4 صيغ). أصبحت لقطة المصدر الفعلية خلفية كاملة بلا لوحة أو تدرّج داكن، مع إبقاء نصوص الحزم، وإبراز شعار «رِواق» والنصوص بظلال وتحديد خفيف، والإبقاء على الإطار المستطيل الخارجي بنفس موضعه مع تباين أعلى قليلًا. لم تُولّد أو تُستبدل أي وجوه.

**حالة Google Drive:** لم تُعدّل ملفات Drive ولم تُنشأ نسخ مكررة. أداة تحديث المحتوى المتاحة لا تتيح تمرير ملف صورة محلي إلى ملف قائم، بينما أداة الرفع بالمسار تنشئ ملفًا جديدًا؛ لذلك بقيت معرّفات وأسماء ومجلدات الأغلفة السابقة كما هي. الأغلفة الجديدة وبياناتها المحلية جاهزة تحت مجلدات الحزم، وتوضح `drive_receipt.json` أن المزامنة داخل المعرّفات الحالية ما زالت معلّقة.
