# Riwaq Editorial Workflow

1. Read `docs/RUWAQ_EDITORIAL_STANDARD.md` at repo root. Do not copy its contents into this skill; it is the maintained authority.
2. Read `data/brand.json` before any visual task, and `docs/RUNBOOK.md` before any actual production/render.
3. Identify the current stage: G0 Idea, G1 Fact-check, G2 Script, G3 Packaging, G4 Production, G5 QC/Release, or G6 Post-publication analytics.
4. Apply the required gate; return GO / REVISE / STOP with the missing evidence, when appropriate.
5. End with the terse standard handoff fields from Section 11. Do not publish or spend credits without explicit authorization.
