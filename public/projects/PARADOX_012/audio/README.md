## كيف بُني الصوت
- **المصدر**: Google Drive → `Premium Trend Shorts Series` → الفيديو المجزأ
  `مركزية العلاقة مع الله _ ياسر الحزيمي _ بودكاست بدون ورق` (27 جزءًا × 480 ثانية).
- القطاع المطلوب **02:38:16.00 → 02:41:13.00** يقع عبر حدّين:
  الجزء 20 (من 376s حتى نهايته) + الجزء 21 (من 0 حتى 73s).
- نقطة الخروج مُدّدت ~2s عن بريف 02:41:11 حتى نهاية كلمة «الفلاح» الختامية
  (الصمت الصوتي المؤكد عند 176.97s، قبل بدء الموضوع التالي «طيب أبو بدر...»).

```bash
ffmpeg -ss 376 -i "part20.mp4" -t 104 -vn -ac 1 -ar 48000 v1.wav
ffmpeg -i "part21.mp4" -t 73 -vn -ac 1 -ar 48000 v2.wav
ffmpeg -f concat -safe 0 -i list.txt -c copy voice_raw.wav
# loudnorm بمرحلتين إلى I=-16:TP=-1:LRA=11  →  voice.wav
```

## كيف بُنيت المزامنة (`../timestamps_paradox.json` — REAL_SYNC)
1. استُخرجت **الترجمات العربية المدمجة** (mov_text) من ملفي المصدر نفسهما —
   وهي ترجمات يوتيوب التلقائية لهذا الصوت بعينه، فالنص والتوقيتات أصلية.
2. فُكّ تكرار الترجمات المتداولة (rolling captions) لاستخراج تيار كلمات نظيف (366 كلمة).
3. حُوذيت حدود الكلمات على **موجة الصوت الفعلية** (طاقة RMS كل 10ms + إلصاق بنقاط الصمت).
4. تنظيف لغوي محافظ: حذف الحشوات (ا/ام)، توحيد التاء المربوطة، تصحيح هفوات ASR واضحة.
   الناتج: 42 فقرة / 314 كلمة بعرض فريمات @30fps، حدود المشاهد عند 86.36s و127.52s.
