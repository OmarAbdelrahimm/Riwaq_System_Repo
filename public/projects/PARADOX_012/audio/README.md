ffmpeg -ss 02:38:16 -i "source_full.mp4" -t 00:02:55 -vn -ac 1 -ar 48000 voice_raw.wav

## المزامنة الدقيقة (قبل النشر — إلزامي)
ملف `../timestamps_paradox.json` حالته **PLACEHOLDER**: كلمات موزعة تقريبيًا
على البنية السردية الثلاثية لغرض المعاينة فقط. قبل أي تصدير نهائي:
1. مرّر `voice.wav` على Whisper (word-level timestamps).
2. حوّل الناتج لنفس بنية JSON (fragments → words: start_frame/end_frame عند 30fps).
3. حدّث `sync_status` في الميتا إلى `whisper_synced`.
4. فعّل `ENABLE_AUDIO = true` في `src/compositions/Main.tsx`.
