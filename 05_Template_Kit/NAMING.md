# NAMING — نظام التسمية والإصدارات

**القاعدة الأولى:** أي ملف يمكن معرفة محتواه من اسمه دون فتحه. **القاعدة الثانية:** لا مسافات ولا حروف عربية في أسماء ملفات التسليم (تبقى العربية للمحتوى وللعرض).

## 1) مُعرّف الفيديو (ID)
- قصير وثابت: `D04` · `EP12` · `RIW_005`.
- لا يُعاد استخدام مُعرّف أبدًا، ولا يتغير بعد أول تسليم.
- للمسلسلات: `<SERIES>_<NN>` مثال: `HERITAGE_07`.

## 2) بنية المجلد
```
projects/<ID>/
├── episode_meta.json          ← مصدر الحقيقة الوحيد
├── inputs/                    ← سكريبت، مصادر، قوائم قطع
├── audio/                     ← VO، المادة الأصلية، الموسيقى، المكس
├── outputs/                   ← كابشنز، بروكسي
├── exports/                   ← كل الملفات المُسلَّمة
└── reports/                   ← تقرير الجودة + المصادر
```

## 3) تسمية الملفات
| النوع | النمط | مثال |
|---|---|---|
| بيانات الحلقة | `episode_meta.json` | ثابت داخل مجلد الحلقة |
| نص التعليق | `VO_<ID>_script.md` | `VO_D04_script.md` |
| صوت خام | `VO_<ID>_<profile>.wav` | `VO_D04_omar_el_clone_v1.wav` |
| المادة الأصلية | `original_<ID>.wav` | `original_D04.wav` |
| مكس نهائي | `mix_final_<ID>.wav` | `mix_final_D04.wav` |
| كابشنز | `CAPTIONS_<LANG>_<ID>.srt` | `CAPTIONS_AR_D04.srt` |
| كابشنز كلمة-بكلمة | `CAPTIONS_<LANG>_<ID>.json` | `CAPTIONS_AR_D04.json` |
| ماستر أرشيفي | `MASTER_FINAL_<ID>.mp4` | `MASTER_FINAL_D04.mp4` |
| ماستر ويب | `MASTER_WEB_<ID>.mp4` | `MASTER_WEB_D04.mp4` |
| تصدير منصة | `EXPORT_<PLATFORM>_<ID>.mp4` | `EXPORT_VERTICAL_D04.mp4` |
| صورة مصغّرة | `THUMB_<ID>_<A\|B\|C>.png` | `THUMB_D04_A.png` |
| تقرير جودة | `QC_<ID>.md` | `QC_D04.md` |
| قائمة مصادر | `SOURCES_<ID>.txt` | `SOURCES_D04.txt` |
| بيان إنتاج | `MANIFEST_<ID>.md` | `MANIFEST_D04.md` |

**قواعد صيغ الملفات:** كل تسليم فيديو `H.264 + AAC` (ماستر أرشيفي: `ProRes`/عالي المعدل حسب المتاح) · الصوت `WAV 48kHz` للمكس · الكابشنز `UTF-8 بدون BOM`.

## 4) وسم حالة الصوت (إلزامي في اسم التسليم غير المكتمل)
- `OFFICIAL_VO` — التعليق بالصوت الرسمي → يجوز النشر.
- `DRAFT_VO` — بطبقة المسوّدة/البديل → **ممنوع النشر**، ويُكتب في تقرير الجودة.
- مثال: `MASTER_WEB_D04_DRAFT_VO.mp4`

## 5) الإصدارات
- المستودع: `vMAJOR.MINOR.PATCH` (تغيير تصميمي = MINOR، تغيير معماري = MAJOR).
- `CHANGELOG.md` إلزامي: ماذا تغيّر · لماذا · من اعتمد · التاريخ.
- الثيم والصوت لهما إصدار مستقل داخل `brand.json → versions`، وكل تسليم يسجّل إصدارات الثيم والصوت المستخدمة.
- **Golden Master:** نسخة مرجعية معتمدة لكل هوية؛ كل جديد يُقاس عليها بصريًا وصوتيًا.

## 6) الأرشفة والحذف
- لا يُحذف تسليم نهائي إلا بوجود بيان إنتاج كامل (نص + إعدادات + صوت + مصادر + هاش).
- الوسائط الوسيطة (بروكسي، تسلسل إطارات، صوت مؤقت) تُحذف بعد التسليم مع تسجيل ذلك.
- السجلات التي تبقى دائمًا: `episode_meta.json` · `QC` · `SOURCES` · `MANIFEST` · الإعدادات (الثيم/الصوت).

## 7) ممنوع
`final_v2_final_ok.mp4` · `نسخة أخيرة.mp4` · `MASTER(1).mp4` · أي اسم فيه: مسافات، أقواس، نسخ متعددة، أو حروف عربية في ملفات التسليم التقنية.
