# AGENTS.md — RUWAQ shared instructions (Codex / Work / other agents)

Before any Riwaq research, writing, thumbnail, video, analytics or production task, read:
1. `docs/RUWAQ_EDITORIAL_STANDARD.md` — canonical editorial, evidence, performance and approval policy.
2. `data/brand.json` — canonical visual/audio brand configuration (do not override).
3. `docs/RUNBOOK.md` — technical production and QC workflow, when execution is requested.
4. `ASSETS_LICENSE.md` — rights and source tracking.

Operate within the specific user request. Ground claims in actual evidence, label hypotheses, preserve original work, and do not invent analytics, historical facts, verified renders, credits or delivery success. Do not publish, spend credits, alter channel settings or run final production without explicit authorization. Finish with the concise handoff format in Section 11 of the editorial standard. When a prerequisite is missing, use BLOCKED/NOT VERIFIED rather than fabricating success.
