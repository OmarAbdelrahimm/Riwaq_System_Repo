# دليل GitHub — الرفع والريندر السحابي (خطوة بخطوة)

> **الفكرة:** ترفع المشروع **مرة واحدة** على GitHub، وبعدها كل فيديو = ضغطة زر → GitHub يرندر → تنزّل الفيديو جاهزًا. **جهازك لا يعمل إطلاقًا.**
> **الحساب:** مجاني. **الخصوصية:** اختر **Private** — الريندر السحابي يعمل مع الخاص.

---

## 💾 المساحة المطلوبة والتخزين (أرقام مقيسة فعليًا)
| السيناريو | المساحة | ملاحظة |
|---|---|---|
| **zip + فك الضغط** (المسار المعتمد) | **~25 MB** | 11MB مضغوط + 14MB بعد الفك |
| + معاينة محلية (`npm install`) | ~550 MB | `node_modules` = 351MB مقيسة + متصفح الريندر ~150–180MB |
| + ريندر محلي وتصديرات | +5–10 GB | مصادر بروكسي + ملفات ناتجة |

> **لأن الريندر سحابي: لا تثبّت npm إطلاقًا على جهازك.** المشروع كله 25 ميجا، والريندر على GitHub.

### الهارد الخارجي — مسموح ومستحسن، بشروط
| تنسيق القرص | الحكم | السبب |
|---|---|---|
| **NTFS** | ✅ ممتاز | كل شيء يعمل |
| **exFAT** | ⚠️ للملفات والرفع فقط | الروابط الرمزية (symlinks) غير مدعومة → `npm install` قد يفشل |
| **FAT32** | ❌ يُتجنَّب | سقف 4GB للملف الواحد → يقطع الفيديوهات الطويلة |

- معرفة التنسيق: **This PC → كليك يمين على القرص → Properties → File system**.
- كل مسارات السكربتات **نسبية** — تغيّر حرف القرص لا يكسر شيئًا.
- **لو أردت `npm install` يومًا ما:** نفّذه على **C: (SSD)** — أسرع وبلا مشاكل روابط، أو على الهارد إن كان NTFS.
- **نسخ احتياطي:** GitHub = نسخة الكود الآمنة · الهارد = الميديا. احتفظ بأصول البراند والصوتيات في مكانين (درايف + هارد).
- خلي **5GB فاضية** على الأقل على الهارد للراحة.

## ⭐ الطريقة الأسهل على الإطلاق — اضغط مرتين (لا أوامر)
1. فك ضغط الحزمة في مجلد على القرص (مثال: `E:\riwaq-system`).
2. افتح المجلد ← اضغط مرتين على **`START_HERE.bat`**.
3. خلاص. الملف ده بيشتغل من مكانه بنفسه، ويلاقي المشروع، ويشغّل السكربت — مهما كان اسم المجلد أو حرف القرص.

> **تنبيه مهم:** لا تشغّل الأوامر من جذر القرص (`E:\`). لازم تكون داخل مجلد المشروع (الذي يحتوي `package.json`).

## 🅰️ الطريقة الثانية — GitHub Desktop (لو مش محترف Git)
1. نزّل **GitHub Desktop** من: `https://desktop.github.com` وثبّته.
2. سجّل الدخول بحسابك في GitHub (لو مفيش حساب: `https://github.com/signup` — دقيقتان).
3. فك ضغط **`Riwaq_System_Repo.zip`** في مكان ثابت على جهازك — مثال: `D:\riwaq-system`
   > ⚠️ مهم: فك الضغط بحيث تكون الملفات (`package.json` · `src` · `data`...) **في جذر المجلد مباشرة**، وليس داخل مجلد فرعي إضافي.
4. في GitHub Desktop: **File → Add local repository** → اختر المجلد `D:\riwaq-system` → **Add**.
   - لو ظهر تحذير «هذا ليس مستودعًا»: اضغط **create a repository** في نفس النافذة → ثم **Create repository**.
5. اضغط الزر الأزرق **Publish repository** (أعلى الصفحة) →
   - الاسم: `riwaq-system`
   - **أزل علامة** «Keep this code private» ✅ → خلّيها **Private** (زي ما هي).
   - **Publish repository**.
6. تم الرفع ✅ — انتقل للقسم **🔵 تشغيل الريندر**.

## 🅱️ الطريقة الاحترافية — Git + السكربت (سطر أوامر)
### مرة واحدة فقط: ثبّت Git
- نزّل **Git for Windows**: `https://git-scm.com/download/win` → ثبّت بالإعدادات الافتراضية.
- (اختياري لكن يسهّل جدًا) ثبّت **GitHub CLI**: `winget install GitHub.cli`
### ثم شغّل السكربت المرفق
1. فك ضغط المشروع في `D:\riwaq-system` (نفس الملاحظة أعلاه: الملفات في الجذر).
2. افتح **PowerShell** داخل المجلد → اضغط `Shift + زر الفأرة الأيمن` → **Open PowerShell here** (أو اكتب في الشريط العلوي للمجلد: `powershell` واضغط Enter).
3. شغّل:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\push-to-github.ps1
   ```
4. السكربت هيسألك: اسمك · إيميلك · اسم المستودع · خصوصيته → **وهو يرفع كل حاجة تلقائيًا** (لو GitHub CLI مثبت).
   - لو مش مثبت: السكربت هيطلعلك رابطين تنفذهم يدويًا (أمر واحد لكل سطر).

## 🅲 الطريقة السريعة — الرفع من المتصفح (لو المشروع صغير)
1. `https://github.com/new` → الاسم `riwaq-system` → **Private** → **Create repository**.
2. في الصفحة التالية: **uploading an existing file**.
3. اسحب **محتويات** المجلد (مش المجلد نفسه) وأفلتها → اكتب رسالة الـCommit → **Commit changes**.
   > ملاحظات: المتصفح يرفض ملفات أكبر من 25MB، والمشروع كله ≈ 14MB فلا مشكلة. تأكد أن المجلدات (src · data · public · scripts · .github) رُفعت بنفس البنية — لو اختفت بنية، استخدم الطريقة 🅰️.
   > **مهم:** تأكد أن مجلد `.github` مرفوع (المتصفح قد يخفيه لأنه يبدأ بنقطة) — بدونه لن يعمل الـWorkflow.

## 🔵 تشغيل الريندر
1. افتح مستودعك على GitHub → تبويب **Actions**.
   - أول مرة: لو ظهر زر أخضر **I understand my workflows, go ahead and enable them** → اضغطه.
2. من القائمة اليسرى اختر **render-episode** → يمين: **Run workflow ▾**.
   - **project_id:** اكتب `GOLDEN_001`
   - **draft:** خلّيها «لا» للنسخة الكاملة (أو «نعم» لمسوّدة سريعة بنصف الدقة)
   - اضغط **Run workflow** (الزر الأخضر).
3. اضغط على التشغيل الجاري لمشاهدة الخطوات لحظة بلحظة (كل خطوة بأخضر لما تنجح).
4. بعد انتهاء التشغيل (3–6 دقائق للاختبار الذهبي): انزل لأسفل صفحة التشغيل → قسم **Artifacts** → نزّل **`GOLDEN_001-deliverables`**.
   - بداخله: الفيديو (MP4) + كابشنز AR/EN (SRT) + تقرير الجودة (QC.md).
   > Artifacts تُحفظ 30 يومًا — نزّلها واخزّنها في مكانك المعتاد (الـHDD).

## 🔁 بعد كده — فيديو جديد (وأنت مرتاح)
1. على جهازك: انسخ مجلد `data\projects\GOLDEN_001` → سمّه بمعرّف جديد، مثال: `D04`.
2. عدّل فيه `episode_meta.json` (النصوص · التوقيتات · الكابشنز) — ولو حطيت أصوات جديدة ضعها في `public\projects\D04\audio\`.
3. في GitHub Desktop → اكتب رسالة التغيير → **Commit** → **Push** (أو المتصفح: ارفع الملفات المعدّلة).
4. Actions → Render workflow → اكتب `D04` → Run → نزّل النتيجة. ✅

## 🆘 حلول المشاكل الشائعة
| المشكلة | الحل |
|---|---|
| الخطوة الحمراء عند **Render** | افتح السجل واضغط على آخر 20 سطرًا وابعتهم لي — الأغلب سببها فشل تزيل المتصفح، والحل: أعد التشغيل (Run workflow) مرة ثانية |
| **Artifacts** فاضية | تأكد أن `project_id` مكتوب بنفس اسم المجلد حرفيًا (حساس لحالة الأحرف) |
| الفيديو طالع بأحرف مقطّعة | تأكد أن مجلد `public/fonts` مرفوع كاملًا (5 ملفات TTF) |
| الـActions مش ظاهرة في القائمة | اضغط زر التفعيل الأخضر أول مرة (انظر خطوة 1) |
| **`The argument '.\push-to-github.ps1' does not exist`** | أنت خارج مجلد المشروع (شغّلت من `E:\`) — الحل: اضغط مرتين على `START_HERE.bat`، أو `cd` لمجلد المشروع أولًا |
| **مش فاكر فكيت الضغط فين؟** | شغّل هذا الأمر ليبحث لك: `Get-ChildItem -Path E:\ -Recurse -Filter push-to-github.ps1 -ErrorAction SilentlyContinue \| Select -First 3 FullName` |
| العربية طالعة رموز غريبة في النافذة | استخدم `START_HERE.bat` (يضبط الترميز تلقائيًا) |
| تجاوزت الحصة الشهرية (خاص) | اجعل المستودع **عامًا** = ريندر بلا حدود (لكن أي حد يقدر يشوف الملفات — للكود فقط، والأصوات/البراند تبقى في مكان آخر) |
| ريندر بطيء جدًا | استخدم `draft: نعم` للمراجعة، ثم الكامل للنسخة النهائية |
| حسابك على GitHub من مزايا الطلاب | بلا حصة قلق — الفريق يمنح دقائق إضافية |

## 🧭 تشخيص سريع — "مش عارف المجلد فين؟"
```powershell
# ابحث عن السكربت في أي مكان على القرص E
Get-ChildItem -Path E:\ -Recurse -Filter push-to-github.ps1 -ErrorAction SilentlyContinue |
  Select-Object -First 3 FullName
```
بعد ما يطلعلك المسار، انسخه واستخدمه:
```powershell
cd "E:\المسار\الذي\ظهر"
powershell -ExecutionPolicy Bypass -File .\push-to-github.ps1
```
> **أو ببساطة:** افتح المجلد في مستكشف الملفات ← كليك يمين في فراغ ← **Open in Terminal** (ويندوز 11) أو **Open PowerShell here** (ويندوز 10 مع Shift+كليك) ← ثم شغّل الأمر.

## 🔒 أمان وملاحظات
- **ارفع الكود والإعدادات فقط** — لا ترفع مواد مصدر محمية بحقوق أو أصول عملاء في مستودع عام.
- الأصوات والنصوص والبراند ملكك؛ مجموعتنا الآن **Private** فلا مشكلة.
- سرعة الرفع لاحقًا: تعديلات صغيرة (ملف البيانات + الأصوات) = ثوانٍ.
- يمكنني تجهيز **فئة مستودع ثانية** لأي عميل جديد لاحقًا بنفس النظام (Theme منفصل، نفس المحرك).
