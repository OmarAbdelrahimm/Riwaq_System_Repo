# دستور إنتاج الفيديو — رواق

> **هذا الملف يُقرأ قبل أي فيديو جديد، أيًّا كانت فكرته أو سلسلته.**
> ليس خاصًا بسلسلة «مركزية العلاقة مع الله»؛ هو الإطار العام، والملفات الأخرى (السيو، الأغلفة، التسمية) فصولٌ منه لا بدائل عنه.
> آخر تحديث: 2026-10-24 · الإصدار 1.0

---

## 0) القاعدة الأصلية: لا قرار بلا دليل

كل رقم أو ادعاء يدخل قرارًا (كلمة مفتاحية، إحصائية، مشاهدات، نسبة إكمال، CTR، نصيحة أداة) يجب أن يحمل **ثلاثة أشياء**:

| # | العنصر | مثال |
|---|---|---|
| 1 | **المصدر** | لوحة vidIQ للقناة · YouTube Analytics · تقرير WEF 2025 |
| 2 | **التاريخ** | 2026-10-22 |
| 3 | **الحالة** | **مقيس** (قرأته من المصدر) أو **مفترض** (تقدير/خبرة/استنتاج) |

**القواعد الفرعية الملزمة:**

1. **المفترض يُعلَن مفترضًا.** لا يُقدَّم تقدير كأنه قياس — لا في التسليم ولا في الشرح ولا في التوثيق.
2. **المفترض له موعد مراجعة.** كل بند «مفترض» يُسجَّل في `docs/KEYWORD_EVIDENCE.md` مع تاريخ إعادة قياسه.
3. **لا توسّع قرارًا مبنيًا على افتراض.** لا تُنتج 10 فيديوهات على كلمة لم تُقَس؛ أنتج واحدًا، قِس، ثم وسّع.
4. **القياس يتغيّر.** أي رقم أقدم من 60 يومًا يُعاد قياسه قبل استخدامه في قرار جديد.
5. **الأداة ليست حكمًا.** درجة vidIQ أو أي أداة = مؤشر تشخيص، وليست هدفًا. الهدف الحقيقي: CTR ونسبة الإكمال.

> **من أين جاءت هذه القاعدة؟** من خطأ فعلي: بُني قرار الكلمة المفتاحية على درجة `66` قرأناها سابقًا، ثم قُدِّم القرار لاحقًا في تسليم دون بيان أنه **رقم قديم غير مُعاد قياسه**. القاعدة تمنع تكرار ذلك لأي كلمة، ولأي فيديو، ولأي رقم.

## 1) مراحل الإنتاج الثماني — والقاعدة الحاكمة في كل مرحلة

### ① الفكرة والكلمة المفتاحية
| البند | القاعدة |
|---|---|
| الكلمة | **واحدة** لكل فيديو، مكتوبة قبل الكتابة لا بعدها |
| الاختيار | من بيانات مقيسة (درجة الأداة / نيّة بحث / أداء فيديو سابق) + تسجيل المصدر والتاريخ |
| التسجيل | سطر إلزامي في `docs/KEYWORD_EVIDENCE.md` بحالة «مقيس» أو «مفترض» |
| الفكرة | تُصاغ في جملة واحدة؛ لو احتاجت جملتين فهي فيديوان |

### ② السكربت والبنية
| البند | القاعدة |
|---|---|
| المدة | 3–6 دقائق للطويل · 40–65 ثانية للشورت |
| البنية | هوك (أول 15 ثانية) → وعد → ثلاث نقاط → خاتمة تسأل سؤالًا |
| الفصول | تُخطَّط **داخل السكربت** بتوقيتاتها، لا تُستخرج لاحقًا بالتخمين |
| الاقتباس | كل اقتباس يُفرَّغ من الصوت؛ لا صياغة بالمعنى |
| الرقم | أي إحصائية في السكربت تحمل مصدرها وتاريخها — تُنقل كما هي إلى الوصف |

### ②.٥ الأصول والحقوق (بوابة قبل المونتاج)
| البند | القاعدة |
|---|---|
| البوابة | **لا مونتاج قبل `check_asset.py`**: صفر أصل ناقص · صفر أصل تحت `min_w` · صفر رخصة غير مكتوبة |
| `min_w` | مشتق لا مخترع: `min_w = عرض المخرج × 1.5` (1080 ⇒ **1620** · 1920 ⇒ **2880**) |
| الأصل الصغير | يُقصّ أو يُستبدل أو يصبح جرافيك. **ممنوع black bars وممنوع تمديد** |
| يوتيوب | اقتباس ناقد فقط: **≤ 8 ثوانٍ** للقطة · 10–20% من المصدر · تعليق ظاهر فوق المادة |
| الرخصة | تُكتب باسمها الصريح + تاريخ الجلب. **`NC` ممنوع** في شغل تجاري |
| السجل | `reports/ASSETS_<ID>.md` — جدول: الملف · المصدر+URL · الرخصة · التاريخ |
| التفصيل | `docs/ASSET_SOURCING.md` |

### ③ الصوت والكابشن
| البند | القاعدة |
|---|---|
| التزامن | الكابشن من طاقة الصوت، لا من تقدير يدوي |
| الكلمات | 3 كلمات لكل كابشن، والكلمة المنطوقة مميزة |
| المربع | شفاف، بلا تكبير، بلا نصف مربع فارغ في الشورت |
| **لوحة السطوع** | استثناء مضبوط: عند سطوع الخلفية العالي (`luma > 0.46`) تُطفأ طبقة **مسطّحة** بشفافية محسوبة — **لا تدرّج**، وتختفي وحدها على الخلفية الداكنة. القرار **لكل مشهد لا لكل كادر** (وميض اللوحة أسوأ من غيابها)، ويُحسب بـ`scrim_map.py` بمقياس **الوسيط** لا المتوسط (لمعة واحدة ما تقرّرش) |
| الموسيقى | هوية ثابتة + خفض تلقائي تحت الصوت (ducking) |
| الملفات | `SUB-AR` + `SUB-EN` + `SUB-BI` دائمًا — الثلاثة |

**مصيدة burn-in مع libass (مقيسة 2026-10-27):** الأرقام العربية-الهندية `٠١٢٣` تُرسم **معكوسة** في مسار `ffmpeg/ASS` (اختبار على `١٤٠٠` ⇒ ظهرت `٠٠٤١`)، و`LRM`/`FSI` **لم يصلحاها**. الأرقام اللاتينية `1400` تُرسم صحيحة. ⇒ في أي كابشن محروق عبر libass تُكتب الأرقام لاتينية؛ ولغة الواجهة إن لزمت العربية-الهندية تبقى في المراحل التي يرسمها المتصفح (Remotion) لا في libass.

### ④ الأغلفة
| البند | القاعدة |
|---|---|
| الإطار | `frame_v3` فقط: خطان أفقيان 2px + خطان رأسيان 1px يتلاشيان عند الزوايا + خط التوقيع. **لا أقواس، لا bevel، لا 3D** |
| الصورة | `isolate()`: وسط مضيّء وأطراف تنطفئ. **لا ضباب على الوجه** |
| الترقيم | «ب»: كبسولة صغيرة داخل الإطار أعلى‑يمين |
| العدد | **اثنان** A وB لكل فيديو، فكرتان مختلفتان لا لونان |
| الاقتران | A↔A و B↔B مع العنوان. الغلاف يحمل النبض، والعنوان يحمل البحث |
| الاختبار | 168px إلزامي قبل الرفع |

### ⑤ حزمة السيو
كل تفاصيلها في `docs/SEO_RULES.md`، وأهمها: الكلمة في العنوان + أول 100 حرف + أول وسم، وسقف 500 حرف، وثلاث ذكرات لا أكثر.
**القاعدة العامة هنا:** السيو لا يُعاد اختراعه لكل فيديو؛ يُولَّد من مصدر واحد ويُفحَص آليًا.

### ⑥ التسمية والتسليم
| البند | القاعدة |
|---|---|
| النمط | `{NN|Snn}-{KIND}-{A|B}-{english-slug}-v{n}.{ext}` |
| اللغة | **لاتيني فقط** في أسماء الملفات. العربية للمحتوى لا للأسماء |
| المصدر | `scripts/publish/naming.py` — لا تسمية يدوية أبدًا |
| مجلد القاعدة | كل فيديو له مجلد واحد، وكل ملفاته داخله، واسمه لاتيني: `04-EP-<slug>` · `S07-SHORT-<slug>` · `CMP-COMPILED-<slug>` |
| التجميع | الحلقة المجمّعة تُنتَج بأدوات الحلقات نفسها (`compiled_pack.py`) — لا أغلفة ولا حزم بمسار موازٍ |
| الحذف | ما لن يُستخدم يُحذف (سلة أولًا)، لا يُؤرشَف |

### ⑦ النشر
| البند | القاعدة |
|---|---|
| الترتيب | لا يُنشر فيديو بغلاف أو عنوان أو سيو من إصدار سابق |
| التثبيت | التعليق المثبّت من حساب القناة خلال أول 30 دقيقة |
| القائمة | إضافة لقائمة التشغيل بالترتيب الصحيح |
| التغيير | لا تغيّر العنوان والغلاف والوصف في يوم واحد |

### ⑧ القياس والقرار التالي
| البند | القاعدة |
|---|---|
| المقياس | CTR (4–6%) ونسبة الإكمال — لا Package Score |
| التوقيت | 48 ساعة = قراءة أولى · 7 أيام = قرار |

## 1.٥ سياسة الحركة — المؤثرات تُطلب بإذن

الفلسفة الافتراضية: **اقطع، لا تُبهِر.** لكن الهدوء ليس قاعدة أبدية — أحيانًا الجملة تحتاج دفعة. الفرق أن الدفعة **قرار مُعلَن** لا عادة مونتاج.

| المؤثر | المدة | السقف/فيديو | متى يُستخدم | ممنوع قربه |
|---|---|---|---|---|
| `flash` | 160ms | **1** | أشرس قطع واحد فقط | أول 500ms · شاشة النهاية |
| `whip` | 220ms | **2** | حدود مقارنة أو انتقال بين مكانين | أول 500ms · بطاقة اقتباس |
| `zoom_punch` | 420ms · `1.12` | **1** | جملة واحدة هي ذروة الفيديو | أول 500ms |
| `shake` | 220ms · ≤8px | **2** | جملة مقاومة/صادمة تُنطق | فوق كابشن · شاشة النهاية |
| `rise` | 500ms | **2** | كشف معلومة — **البديل الهادئ للـflash** | — |
| `spin` · `bounce` | — | **0** | ممنوعتان مطلقًا | — |

**قواعد ملزمة:**
1. **تُسأل قبل الاستخدام.** يُقال: الموضع بالثانية · الوظيفة · البديل الهادئ ⇒ ثم يُقرَّر. (مضبوط في `data/brand.json → theme.motion.effects_policy`.)
2. **ميزانية:** ≤ 2 مؤثر/دقيقة · مؤثر واحد في اللحظة · لا مؤثران متجاوران.
3. **لا فوق وجه ولا أثناء كابشن ولا في أول 500ms** (نافذة الهوك مقدّسة).
4. **كل استخدام يُسجَّل** في `reports/MOTION_LOG_<ID>.md`: الموضع · النوع · السبب · **البديل الذي رُفض** ولماذا.
5. **الافتراضي عند الشك:** `hard_cut` + `fade_black_200ms`. إن لم تستطع تبرير المؤثر بجملة واحدة، فهو زينة.

**التوازن:** `ken_burns 1.0→1.06` باقٍ كما هو. `zoom_punch` مختلف: دفعة قصيرة على جملة، لا زووم مستمر.

## 2) ما يمنع تكرار المشكلة

| المشكلة التي حدثت | القاعدة التي تمنعها | من يفرضها |
|---|---|---|
| كلمة مفتاحية غابت عن 5 حلقات | المرحلة ⑤ كاملة | `seo_pack.py` (فحص آلي) |
| أسماء ملفات عربية/قديمة على Drive | المرحلة ⑥ | `naming.py` |
| إطار غلاف أُعيد تصميمه 3 مرات | المرحلة ④ | `cover_system.frame_v3` |
| رقم قُدِّم كأنه مقيس | القاعدة ٠ | `docs/KEYWORD_EVIDENCE.md` |
| تسليم بلا دليل | القاعدة ٠ | سطر الدليل في كل حزمة (فحص 8) |
| اسم ملف خارج النمط | المرحلة ⑥ | `naming.py --check` |
| مونتاج على أصل ناقص أو غير مرخّص | المرحلة ②.٥ | `check_asset.py` |
| مؤثر حركي أُضيف بالعادة | §1.٥ | `MOTION_LOG` + سؤال قبل التنفيذ |
| ملف ثقيل/بلا faststart | `docs/EXPORT_SPEC.md` | فحوص ما بعد التصدير |

## 3) كيف تُفرَض القواعد (أوامر لا نيّة طيبة)

```bash
# ①–⑤  الحزمة: يولّد ويكتب ويفحص (منها سطر الدليل واسم الملف)
python3 scripts/publish/seo_pack.py

# ⑤      فحص الموجود فقط، بلا كتابة
python3 scripts/publish/seo_pack.py --audit

# ⑥      فحص أي اسم ملف قبل رفعه إلى Drive (0 = مطابق)
python3 scripts/publish/naming.py --check S04-VID-be-better-not-the-best-v1.mp4

# ⑥      فحص اسم مجلد Drive قبل إنشائه/تسميته
python3 scripts/publish/naming.py --check-folder 04-EP-shaytan-runs-through-the-blood

# ⑧      فحص الملف المسلَّم نفسه (exit 0 = يمر)
python3 scripts/qc_media.py exports/…-VID-<slug>-v1.mp4 --aspect 9x16

# ③      خريطة اللوحة التكيفية لهذا المصدر + حقن luma في أسطر الكابشن
python3 scripts/scrim_map.py exports/MASTER.mp4 --aspect 9x16 \
  --out data/projects/<ID>/scrim_map.json \
  --apply public/projects/<ID>/captions.json
```

**الفحص يفشل = لا تسليم.** الأوامر الثلاثة تُشغَّل في نهاية كل جولة، ونتيجتها تُذكر في التسليم.

## 4) قائمة قبل تسليم أي فيديو

- [ ] الكلمة المفتاحية مسجّلة بدليلها (مصدر/تاريخ/حالة)
- [ ] الفصول مُخطَّطة داخل السكربت ومطابقة للفيديو
- [ ] ثلاثة ملفات ترجمة (AR / EN / BI)
- [ ] غلافان A/B بالإطار v3، ومرّا اختبار 168px
- [ ] حزمة سيو عدّت الفحص الآلي بلا مخالفة
- [ ] كل أسماء الملفات لاتينية بنمط `naming.py`
- [ ] لا ملف قديم أو مكرر داخل المجلد
- [ ] التعليق المثبّت وقوالب الرد جاهزة
- [ ] بوابة الأصول عدّت (`check_asset.py` ⇒ exit 0) وسجل الحقوق مكتمل
- [ ] المؤثرات الحركية كلها مسجّلة في `MOTION_LOG` بموافقة مسبقة
- [ ] ملف المنصّة صادر بـ`crf 21` + `+faststart` + `keyint 60` (الماستر يبقى 18)
- [ ] فحوص التصدير: `LRA ≤ 8` · صفر black · حِدّة النص ≥ 0.85× المرجع
- [ ] `preview_720p.mp4` مرفق مع الماستر
- [ ] `qc_media.py` عدّى على الملف المسلَّم (`exit 0`) — لا رفع على `FAIL`
- [ ] `scrim_map.json` مولّد من المصدر الفعلي، ولا لوحة مفعّلة يدويًا
