# تحليل أي فيديو مرجعي — قياسي، لا انطباعي

> الأداة التي أنتجت `docs/reference/ref_metrics.json`. تعمل على أي MP4/MOV وبدون أي خدمة خارجية.
> الهدف: تحويل «الفيديو حلو» إلى أرقام قابلة للنسخ في الإنتاج.

## التشغيل

```bash
python -m venv .venv && .\.venv\Scripts\activate      # ويندوز
pip install -r scripts/requirements-analyze.txt

python scripts/analyze_reference.py "C:\path\ref.mp4" docs/reference/out
```

المخرجات في مجلد الخرج:

| الملف | المحتوى |
|---|---|
| `REPORT.md` | تقرير عربي مقروء: المدة، اللقطات، اللوحات، الصوت، الحركة |
| `report.json` | نفس البيانات خامًا (آلة تقرأ) |
| `sheet_A.jpg` / `sheet_B.jpg` | 24 إطارًا موزعة مع توقيتات |
| `sheet_open.jpg` / `sheet_end.jpg` | الافتتاح والخاتمة بتفكيك 0.35s |
| `hero_*.png` | إطارات كاملة الدقة عند اللقطات المفتاحية |

## ما يقيسه بالضبط

| المقياس | الطريقة | لماذا يهم |
|---|---|---|
| القطعات | `ffmpeg select='gt(scene,0.20)'` | إيقاع الفيلم = قانون أول في التقليد |
| طاقة الحركة | فرق متوسط البكسل بين إطارات مصغّرة 160px | يكشف السكون المقصود (نصف الفيلم في المرجع) |
| لوحة الألوان لكل لقطة | تكميم 5 ألوان MedianCut | كشف «قاعدة اللون» (محايد غلاف / ملوّن داخل) |
| ترتيب اللقطات والمدد | حدود القطعات | كشف «مركّز ← برق ← سكون» |
| Loudness · LRA · TP | `ffmpeg loudnorm` | هل الصوت مخلوط لمعيار أم لا (المرجع −20 LUFS) |
| طاقة تحت 300Hz | FFT | الوزن الصوتي (باس ثقيل = فخامة) |
| **طابع الكلام** | معامل التعديل المقطعي 1.5–8Hz | يكشف وجود تعليق/بصمة بشرية من عدمه |
| الصمت | `silencedetect -38dB:d=0.3` | الصمت النهائي تحت الـCTA توقيع فخامة |
| OCR (اختياري) | Tesseract على الإطارات | سحب النص الظاهر لما لا يوجد سكربت |

## قواعد حاكمة عند القراءة

1. **لا تحكم من إطار واحد.** القيمة في المدد والترتيب، لا في جمال إطار.
2. **الصوت نصف الفيلم.** أي تحليل بدون الصوت ينتج تقليدًا أعمى.
3. **المرجع ليس معيار نشر.** لو كان −20 LUFS فهذا اختيار فني، لا تنسخه للبث — انسخ منه *العلاقة* لا الرقم.
4. **افصل «قاعدة» عن «أصل».** قاعدة اللون تُنسَخ؛ أعمال العميل تُستبدل.

## ملاحظات تشغيل

- يحتاج `ffmpeg` في الـPATH. على ويندوز: `winget install Gyan.FFmpeg`.
- على ملفات Drive: نزّل الملف أولًا (الأدوات السحابية قد تمنع الوصول المباشر).
- الأداة لا تعدّل الأصل، ولا ترفع أي شيء لأي خدمة.
