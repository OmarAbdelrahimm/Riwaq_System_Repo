# من «المرجع» إلى «رِواق» — ماذا نأخذ، وماذا نرفض، وماذا نستبدل

> وثيقة قرار. المرجع: `docs/reference/00_REFERENCE_BREAKDOWN.md`.
> الحالة: **القالب يعمل ومُختبَر** — ريندر 42 ثانية على GitHub Actions، 1260 إطار، 1080×1920.

## 1) الفرق الجوهري: المرجع فيلم إعلاني، ورِواق فيلم سردي

| المحور | `example motion.mp4` (ReLabel) | رِواق |
|---|---|---|
| النوع | showreel تعريفي لستوديو | فيلم وثائقي قصير / شورت تاريخي |
| مدته | 27.6 ثانية | 42 ثانية (Golden) · 30–60 للشورت |
| نسبة الأبعاد | 16:9 مع كادر مقصوص | **9:16 رأسي** هو الأصل |
| اللغة | إنجليزي | عربي (RTL) + ترجمة |
| أصل المحتوى | أعمال عملاء (صور/3D) | لا مادة مصدر — بناء بصري بالكامل |
| الألوان | محايد + ألوان صارخة داخل الشاشات | 10 ألوان مقفولة، ذهبي/عاجي/فحمي |
| الخطوط | sans هندسي | **Amiri** للعناوين + **IBM Plex Sans Arabic** |
| الإيقاع | 12 قطعة / 27.6s (متوسط 2.1s) | 1.5–2.5s للشورت، 3.5–6s للوثائقي |
| الحركة | parallax + 3D خفيف + برق | تقطع مباشر + تلاشٍ 200ms، بلا وميض أو دوران |

**الخلاصة:** المرجع **لا يُنسخ** لأنهما نوعان مختلفان. الذي يُنسخ هو **مبادئ الإحساس**، لا الشكل.

## 2) المبادئ الخمسة التي نأخذها فعلًا (ومكانها في النظام)

| 1 | **توقيع قبل المحتوى** — اسم البراند قبل أي معلومة | هوك 0–4.5s + علامة مائية أعلى الوسط | ✅ موجود (`HookFrame` + `Watermark`) |

## 3) ما نرفضه صراحةً (ومخالفته لكل قواعد رِواق)

| المرفوض | السبب |
|---|---|
| ألوان صارخة في الغلاف | يخالف `palette_lock` و`max_ratio` للألوان |
| 3D مائل / مجسمات / parallax ثقيل | يخالف `motion.forbidden` (لا دوران، لا وميض) |
| لقطة أقصر من 0.5s في فيلم سردي | يخالف أدنى زمن قراءة عربي (28 حرفًا/سطر) |
| لودنس −20 LUFS | يخالف معيار النشر: −14 للفيديو، −16 للبودكاست |
| لقطة واحدة بيضاء ساطعة (flash-frame) | يخالف `negative_rules` — مصدر صداع/رفض خوارزمي |

## 4) الفجوة الحقيقية: المرجع «مليان أصول»، ورِواق «نص وصوت»

المرجع يبدو فاخرًا لأن كل إطار فيه **صورة أصلية عالية الجودة**. رِواق في نسخته الحالية يبني كل شيء من **طباعة + نسيج + صوت**.

| المكوّن | المرجع | رِواق الآن | الفجوة |
|---|---|---|---|
| خلفية بصرية | 12 عمود أعمال + شاشات 3D | نسيج ورق + توهج | **عالي** |
| دليل بصري | شاشات أعمال ومجسمات | مصدر نصي + رقم | متوسط |
| صوت | موسيقى + مؤثرات مُخلوطة | VO + موسيقى + stingers | **منخفض** |
| طباعة | sans بسيط | Amiri/Plex + تشكيل عربي | **رِواق أقوى** |
| مصداقية | لا شيء | مصدر + رقم + مسند ذهبي | **رِواق أقوى** |

**الاستنتاج الحاسم:** لا نحتاج تقليد شكل ReLabel. نحتاج سدّ فجوة **الخلفية البصرية** فقط، لأن طباعة رِواق ومصداقيتها أقوى بالفعل. لذلك الخطة في §5 تتركّز على طبقة `broll`، لا على إعادة بناء الهوية.

## 5) الطبقة الناقصة: `broll` (معلَنة في المخطط وغير منفّذة)

`src/engine/types.ts` يعرّف `"broll"` كنوع مشهد، لكن `SceneRenderer` **لا يعالجه** (يعود `null`). أي:
- كل مشهد `broll` يُخطط في `episode_meta` ثم **لا يظهر** في الفيديو بصمت.
- هذا خطر إنتاجي: تعتقد أن الفيديو فيه 40% لقطات، فتجد 0%.

**المواصفة المقترحة (جاهزة للتنفيذ):**

```ts
// src/components/BrollFrame.tsx
// خلفية بصرية كاملة داخل الإطار مع كين برنز خفيف + تظليل + قناع قابل للقراءة
interface BrollFrameProps {
  src: string;              // من public/projects/<id>/plates/
  durFrames: number;
  captionTop?: number;      // لأعلى مساحة للحقن النصي
  kenBurns?: [number, number];  // من brand.theme.motion.ken_burns
  scrim?: number;           // 0–0.35، ضروري للقراءة فوق الصور
}
```
قيود ملزمة عند التنفيذ:
- الحركة فقط من `motion.ken_burns` (1.0 → 1.06) — لا parallax ولا دوران.
- `scrim` إلزامي ≥ 0.18 إذا وُضع نص فوق الصورة.
- كل صورة يجب أن تمرّ عبر `STYLE_BLOCK.md` (نفس لوحة الألوان، لا وجوه مواجهة).
- نسبة `broll_ratio_max` من `video_type_presets` تُفحص في بوابة الجودة.

## 6) ماذا ينتج إن نفّذنا الطبقة؟

مع `broll` + الإيقاع الحالي + المصداقية النصية، يصبح الفيديو:
**سردي عربي بمظهر سينمائي**، وهذا شيء لا يستطيع المرجع تقديمه أصلًا (لأنه إنجليزي بلا مصدر ولا سرد).
