# Gate protocol — prevents endless iterations / token waste

## G0 — Preflight inventory. Deliver a one-page state report.
PASS only if:
- Exact S01 original audio file and version/hash can be identified; if absent mark MISSING, do silent visual prototype only.
- Official `logo.svg` exists or remains explicitly MISSING; never invented.
- Asset report labels flattened concept vs independent transparent layers vs actual 3D geometry correctly.
- Reference video inspected at 0/4/8/14/18/26/38/50/64/78 seconds.
- Repo and lockfile checked, current failures documented, existing approved files untouched.

## G1 — Styleframe approval
- 2 styleframes, one at the hero and one at the repeated-claim/evidence transition.
- No branded Luminovo UI/logos; authentic RUWAQ colors/text/voice meanings.
- Layer naming and true editable foreground vs backgrounds demonstrated.
- Human visual approval required before significant generation or rendering.

## G2 — 0–6s MOTION PROOF (hard maximum before approval)
The proof MUST include:
1. 2 independently movable hero assets with lighting, reflection and grounded shadows (not just cropped PNG drifting).
2. Depth/parallax camera motion with two truly different depth planes or geometry.
3. Arabic Kinetic Typography matched to real S01 when available; else SILENT TIMING PROTOTYPE badge in report.
4. One visible concept transition from myth warning to question/trace; not an unmotivated fade.
5. No permanent subtitles, no talking head, no anatomy or logo reconstruction.
6. No blank/black edge due to insufficient image cover; text and highlights readable at 360px video width.
7. MP4 6s/180f/30fps; contacts at at least 0/20/40/60/90/120/150/179.
8. Side-by-side 2–3 representative stills against the user reference categories (hero, card, transition) with clearly labeled comparison of style grammar. Do NOT put reference footage in output video.

## Objective pass/fail
Visual motion PASS: moving objects have independent local transform/draw updates after temporarily disabling the global camera animation. Confirm via consecutive PNG frames and note exact frame difference. Static zoom-only = FAIL.
Audio QC PASS only after native Arabic listening and visual timing check; ASR alone = PARTIAL.
Scientific QC PASS only after externally verified claim and correct label/causality, not merely a credible-looking diagram.
Brand QC PASS only with official logo file + no hallucinated mark.
No false approval: rendering success is not art success.

## G3 — After user signs off
Only then build 6–30s and export 0–30 in same continuity. Any failure returns to the **failed scene only**. Do not regenerate previously accepted assets. Lock versions in manifest.

## Reporting discipline
One concise report per attempt: objective; actual artifacts; measurement and visual evidence; known defects; new work vs reused; what approval needed. Avoid lengthy narrated logs of library installs / waiting. Keep memory low, render preview once. Never spin indefinite iterations.
